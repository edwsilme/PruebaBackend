# Proyecto Backend - Validación de datos de Usuario

Este es un proyecto de prueba desarrollado para el puesto de Desarrollador Backend Java.

---

## 🚀 Tecnologías y Herramientas utilizadas

- Java version SDK 21
- IntelliJ IDEA Community Edition 2025.1.3
- REST API (simulada o real)
---

## 🛠️ Características del sistema

- Inicio en plataforma Swagger
- Ingreso de datos formato Json
- Sistema valida los datos.
- En caso de no presentar error, sistema envia datos a base de datos a traves de servicio SOAP

---
